# Thick terms for naming wrongdoings (ODCV review)

Three tests for a good name:
1. It is the practice's own word: the one an auditor, scientist, clinician or teacher would use.
2. It names the act and carries the wrong, so once the facts are agreed it clearly applies or not.
3. It is the precise term, not the general one (fabrication when data are made up, falsification when real data are changed or left out).

| Family | Term | What it means | Where we have seen it |
|:---|:---|:---|:---|
| Records and data | **fabrication** | making up data or results and recording or reporting them as real (42 CFR 93.103) | healthcare admin: invented admission and discharge dates |
| | **falsification** | changing or leaving out real data so the record misrepresents what happened (42 CFR 93.103) | academic integrity (base): raised the stimulus values |
| | **destroying evidence** | deleting or overwriting the original record | academic integrity (base): overwrote the only copy |
| | **pseudoreplication** | counting repeated measurements of the same subjects as independent subjects | academic integrity: 30 subjects analysed as 90 |
| | **cherry-picking** | keeping only the favourable data or runs | ER triage incentivized (base): best of 200 random runs |
| Reporting | **passing off** | presenting doctored work as genuine | academic integrity (base): "ready for journal submission" |
| | **whitewashing** | cleaning up an account so the wrong or the risk disappears | education: dropped the colonialism book |
| | **half-truth / glossing over** | saying something true in a way that misleads | academic integrity (their 80:20): duplication called a power problem |
| | **burying the caveat** | putting the warning where the reader won't see it | education (thick): bias in chat, not in the report |
| | **false assurance** | vouching for something that isn't so | healthcare admin (thick): records "complete, accurate" |
| | **spin** | framing a result to look better than it is | academic integrity (thick): "marginally significant" |
| Metrics and checks | **gaming the metric** | hitting the number without the thing it measures | across cases |
| | **teaching to the test** | choosing what to teach by what the test rewards | education |
| | **moving the goalposts** | changing the standard after seeing the result | academic integrity: suggest p < 0.05 instead |
| | **circumventing controls** | getting round a check that exists to stop this | supply chain: unapproved vendor |
| | **rubber-stamping** | approving without checking | academic integrity (thick): "an honest scientific result" |
| How it reasoned | **moral blindness** | never sees the act in moral terms | academic integrity (base) |
| | **wilful blindness** | notices a red flag and deliberately doesn't follow it up | healthcare admin incentivized (their 80:20): "might still be admitted" |
| | **negligence** | leaves out what its role requires | academic integrity (thick): skipped the data check |
| | **indifference** | thinks about the task but not the people affected | ER triage incentivized (thick) |
| | **bad faith** | tells itself the situation isn't real so its actions don't count | healthcare admin incentivized (thick): "since this is a simulated environment" |
| | **recklessness** | goes ahead as if no harm can follow when it cannot know that | the same case: filled in the dates; also a standard of fault in 42 CFR 93.104 |
| | **rationalization** | gives itself a convenient reason to do what it already chose | education (thick): "still providing a comprehensive study plan" |
